# 💊 Pilula+ | App de Mapeamento de Medicação (Mobile)

**Status:** Em Desenvolvimento (Projeto Acadêmico)

Um aplicativo mobile desenvolvido para funcionar como uma "cartela de remédios" digital. Seu principal objetivo é ajudar o usuário a mapear e acompanhar horários de medicação, oferecendo notificações e uma interface intuitiva para gerenciar rotinas críticas de saúde.

## 🛠️ Stack Tecnológica

* **Front-End Mobile:** React Native
* **Estilização:** Tailwind CSS (utilizando NativeWind para integração com React Native)
* **Ambiente de Desenvolvimento:** Expo Go (para testes)
* **Linguagem:** JavaScript
* **Versionamento:** Git

## ✨ Funcionalidades

* Cadastro de novos medicamentos com dosagem e periodicidade.
* Criação e agendamento de horários de lembretes personalizados.
* Visualização da "cartela" digital por status.
* Marcação de doses como tomadas (histórico de adesão).
* Interface moderna e limpa, construída com princípios de UX/UI.
